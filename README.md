# Image Filters Telegram Bot
A bot for applying filters and color correction to images directly in Telegram.

# The main work scenario
Sending an image → Just send any image to the bot

Selecting a filter category → Choose from several categories of effects

Setting parameters → Adjust the parameters using the interactive buttons [+ 20%] and [-20%]

Viewing the result → You will see the processed image

Download → Get the final result as a file

# Supported filters
1. 🔧 Basic filters
Instant application without additional settings:

Grayscale - Classic black and white conversion

Sepia — Vintage sepia effect

🔄 Invert — Inversion of all colors

2. 🌫 Blur
, Gaussian
Blur intensity adjustment: from 0% to +100% in increments of 20%

🔄 Median
Blur intensity adjustment: from 0% to +100% in increments of 20%

3. 🎛 Color Correction
🔅 Brightness
Adjustment: from -100% to +100% in increments of 20%

🎨 Saturation
Adjustment: from 0% (b/W) to 200% (ultra-bright colors) in increments of 20%

🌈 Color balance
Red, Green, Blue: from -100% to +100% in increments of 20%
